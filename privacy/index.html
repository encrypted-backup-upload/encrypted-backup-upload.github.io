Privacy policy

This policy covers 加密備份上傳工具 and its information website. The tool is for the account holder’s personal use only.

Data access and use

The tool reads the connected account’s email address to confirm that the correct account is in use. It reads identifiers, names, sizes, parent folders, permissions, and checksum information for the selected folder and transferred files to verify the destination and transfer results. It uploads a locally selected, encrypted file to Google Drive and downloads that file to check that its contents match.

Google’s authorization permits viewing, editing, creating, and deleting all Drive files in the account; it is not folder-level authorization. The tool’s current verification process does not delete files from Drive.

Storage and protection

File contents are encrypted locally before upload and transferred over HTTPS. Google Drive still receives metadata such as file names and sizes. Authorization credentials are held in a password manager controlled by the account holder and accessed locally when the tool runs. Transferred files and verification records may remain on the local computer; they are not published on this information website.

Sharing and other uses

Google Drive handles file transfer and storage. The password management service holds the credentials. Google user data obtained by the tool is used only for the account checks and file transfer verification described above. It is not sold, used for advertising, or used to train general-purpose artificial intelligence models.

Retention, deletion, and revocation

Uploaded files remain in the account holder’s Google Drive until the account holder deletes them. Stopping use of the tool or revoking access does not automatically delete existing files in Drive, local verification records, or stored credentials. The account holder can revoke access through the Google Account’s third-party connections settings and separately manage or remove those files, records, and credentials.

Website visits

The information website does not require sign-in, offer a file upload form, or add advertising or analytics tracking. It is hosted on GitHub Pages. GitHub logs visitors’ IP addresses for security purposes, as described in the GitHub Privacy Statement.

Contact

Privacy questions can be sent to the developer support email address shown on Google’s consent screen.
