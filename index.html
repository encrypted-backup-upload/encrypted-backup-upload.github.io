加密備份上傳工具

This is a local tool for personal use. It connects to the account holder’s Google Drive with their authorization and verifies encrypted file uploads by downloading and checking the uploaded files.

How it is used

The account holder starts the process on their own computer and grants access through Google’s consent screen. The tool does not offer public registration or an online backup service. This website provides information only; it does not receive backup files or Google authorization credentials.

Google Drive permissions

Google’s authorization permits viewing, editing, creating, and deleting all Drive files in the account. It is not restricted to a single folder. The current verification process only checks the connected account and the selected destination, uploads an encrypted file, and downloads that same file for comparison. It does not delete files from Drive.

Scope of use

The tool is for the account holder’s own data. Access can be revoked at any time through the third-party connections settings in the Google Account.
